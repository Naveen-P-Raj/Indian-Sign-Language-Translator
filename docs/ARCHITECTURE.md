# System Architecture

```text
                 ┌─────────────────┐
                 │  Webcam / Image │
                 └────────┬────────┘
                          ↓
                 ┌─────────────────┐
                 │     OpenCV      │

                          ↓
                 ┌─────────────────┐

                 └────────┬────────┘
                          ↓
              ┌────────────────────────┐
              │ 21 landmarks / hand    │

              └───────────┬────────────┘
                          ↓
              ┌────────────────────────┐
              │ Wrist-relative          │
              │ normalization           │
              └───────────┬────────────┘
                          ↓
              ┌────────────────────────┐
              │ 126-D feature vector    │
              │ Left 63 + Right 63      │
              └───────────┬────────────┘
                          ↓
              ┌────────────────────────┐
              │ TensorFlow/Keras MLP    │
              │ 128 → 256 → 128 → 36    │
              └───────────┬────────────┘
                          ↓
              ┌────────────────────────┐
              │ Softmax classification │
              └───────────┬────────────┘
                          ↓
              ┌────────────────────────┐
              │ Sign + confidence      │
              └────────────────────────┘
```
